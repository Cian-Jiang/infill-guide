02

按任务选择，而不是追逐“最强”

下面是建议的试验顺序，不是材料厂商认证的专用配置。

FUNCTIONAL

普通功能件 / 小型连接件

立方体 / 螺旋体 / 交叉层叠

先保证打印方向、壁厚与孔位周边的材料，再选择内部图案。

需要相对均匀的核心时，先比较固定密度图案。
PETG

PETG 出现交点刮擦

螺旋体 / Z直线

把同层交叉作为一个排障变量；同时检查流量、体积流量与材料状态。

推荐是试验顺序，不是“PETG 只能用 Gyroid”。
LARGE VOLUME

内部体积大的模型

自适应立方体

中心留有大块空间时，自适应填充才有明显节省的机会。

薄壁盒子通常受壁厚主导，不一定能省很多。
DISPLAY

不承重的摆件 / 雕塑

闪电 / 支撑立方体

目标是托住上表面，而不是建立均匀的承载核心。

有夹紧、螺丝或卡扣需求的区域需要另行加强。
PLANAR

关注平面内刚性

三角形 / 内六边形 / 网格

根据载荷方向和板厚比较，不要把 XY 刚性当作厚度方向抗弯。

同层交叉图案需检查交点是否过度堆料。
SPECIAL

柔性 / 轻量 / 周期结构试验

侧向晶格 / 同心 / 侧向蜂窝

先确定要定向变形、抗扭还是缓冲，再决定是否测试 TPMS-FK。

用相同材料、质量和外壳进行对比，而不只匹配百分比。
先决定零件如何受力，再决定材料放在哪里。

外壳决定边界与表面，稀疏填充补充内部支撑；局部高载荷区常常需要局部加强，而不是整件无差别加密。[4]

04

26 种图案逐项详解

每项包含概念示意、XY / Z 强度、试切密度、材料标签、结构原理与使用边界。配图仅作识别，不是实际切片截图或精确的 TPMS 模型。

密度与标签

建议试切密度不是官方逐图案规格。以下数值是本文为首轮对照设计的范围，前提为 0.4 mm 喷嘴、0.20 mm 层高、已校准材料预设；最终按顶面跨度、壁厚、局部受力与样件结果调整。

材料标签表示选型用途，不是可打印／不可打印认证。“优先试切”是建议的对照基准；“定向／特殊用途”需匹配目标；“需验证／非首轮优先”表示需要额外的小样检查。不能将本表的 XY / Z 评级直接套用到 TPU 成品。

TPU 的硬度、壳厚与变形方向会影响手感；柔性材料桥接较弱，低密度时尤其需要看实际悬空段。[7]一般填充与壁厚的关系参考 [8]。

常见误区与打印排障

把几何问题、材料问题和工艺问题分开，避免只在填充下拉框里反复尝试。

误区 1星级相同，承重就相同

不是。XY 与 Z 星级各自只是方向性定性参考，不包含模型尺寸、载荷类型、破坏模式与安全系数。某一列同为五星，也不代表实物承载能力相同。

误区 2网格必然最能托住顶面

不是。相同材料用量下，直线填充可能有更密的支撑线；还要看第一层实心顶面的桥接方向与有效跨距。

误区 3TPMS 或 Gyroid 能消除层间弱点

不能。理想几何的方向均衡，不等于逐层挤出的成品各向同性；打印方向与层间熔合仍然重要。

误区 4提高填充比加壁永远更有效

没有这种通则。壳体、悬臂、局部压缩和螺钉夹紧的材料需求不同；按失效位置决定先加哪里。

误区 5所有图案的 20% 都等于同样克数

不是。密度计算、路径调整和自适应分布会改变实际耗材；闪电尤其不能当作均匀体积填充理解。

误区 6换成 Gyroid 就能修好 PETG

不保证。图案只能改变路径；受潮、过量挤出、温度、速度与体积流量问题仍需单独排查。

星级越高，分别表示参考耗时较少、参考用料较少。它们不是实际 mm/s、克数或等质量强度；跨档差值没有倍数意义。

03 / 参考切片，不是实物力学试验

当前官方说明使用 Qidi Q2、0.4 mm 喷嘴、0.20 mm 预设与 QIDI PLA Rapido，对方块、3DBenchy 与 Stanford bunny 做多密度切片比较。仅统计相关稀疏填充与空走；强度等级由人工设定。[2]
