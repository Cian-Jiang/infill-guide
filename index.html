02

按任务选择，而不是追逐“最强”

下面是建议的试验顺序，不是材料厂商认证的专用配置。

FUNCTIONAL

普通功能件 / 小型连接件

立方体 / 螺旋体 / 交叉层叠

先保证打印方向、壁厚与孔位周边的材料，再选择内部图案。

需要相对均匀的核心时，先比较固定密度图案。
PETG

PETG 出现交点刮擦

螺旋体 / Z直线

把同层交叉作为一个排障变量；同时检查流量、体积流量与材料状态。

推荐是试验顺序，不是“PETG 只能用 Gyroid”。
LARGE VOLUME

内部体积大的模型

自适应立方体

中心留有大块空间时，自适应填充才有明显节省的机会。

薄壁盒子通常受壁厚主导，不一定能省很多。
DISPLAY

不承重的摆件 / 雕塑

闪电 / 支撑立方体

目标是托住上表面，而不是建立均匀的承载核心。

有夹紧、螺丝或卡扣需求的区域需要另行加强。
PLANAR

关注平面内刚性

三角形 / 内六边形 / 网格

根据载荷方向和板厚比较，不要把 XY 刚性当作厚度方向抗弯。

同层交叉图案需检查交点是否过度堆料。
SPECIAL

柔性 / 轻量 / 周期结构试验

侧向晶格 / 同心 / 侧向蜂窝

先确定要定向变形、抗扭还是缓冲，再决定是否测试 TPMS-FK。

用相同材料、质量和外壳进行对比，而不只匹配百分比。
先决定零件如何受力，再决定材料放在哪里。

外壳决定边界与表面，稀疏填充补充内部支撑；局部高载荷区常常需要局部加强，而不是整件无差别加密。[4]

03

26 种图案逐项详解

每项都按“结构原理—优势—限制—用途—实践提醒”整理；结构定义参考 [1]，场景选择与调试提示为本文建议。

A

直线与之字系列

路径简单，但方向性与层间连接差异不能忽略。

01—06
01Z直线Rectilinear快速入门
XY 强度 ★★☆☆☆ 中低Z 强度 ★☆☆☆☆ 低评分口径 ↗

结构原理 每层铺设一组平行线，相邻层通常旋转 90°。“Z直线”是截图中的菜单译名，并不是沿 Z 轴竖直画线。[1]

优势与价值

路径直观，容易检查挤出是否连续；避免网格那种在同一层交叉处重复经过。

限制与代价

内部线条沿层高交替相接，不代表所有方向都有同样的连接面积；低密度时仍需检查顶面跨距。

适合用途 尺寸验证件、普通轻载外壳，以及希望减少交叉点的简单零件。

实践提醒

对照网格时同时观察第一层顶面实心填充：支撑效果取决于线间距和桥接方向，不能只看图案名字。

02直线排列Aligned Rectilinear定向结构
XY 强度 ★★☆☆☆ 中低Z 强度 ★★★☆☆ 中评分口径 ↗

结构原理 各层保持相同的平行线方向，沿高度形成定向的条带状结构，而不是层层交替换向。[1]

优势与价值

方向明确，适合在已知载荷或变形方向的情况下安排材料；路径也容易检查。

限制与代价

一个方向的良好表现不能代表整个 XY 平面。顶层桥接若与下方线条平行，承托效果可能变差。

适合用途 经过定向设计的内部筋条、需要特定方向变形的样件。

实践提醒

把填充方向和顶层桥接方向一起检查。普通多方向功能件不必优先使用它。

03之字形Zig Zag简单路径
XY 强度 ★★☆☆☆ 中低Z 强度 ★☆☆☆☆ 低评分口径 ↗

结构原理 与直线类填充相近，使用规则的之字形组织路径；实际端部连接和层间方向由切片实现决定。[1]

优势与价值

图案规则，适合观察线条间距、挤出连续性和低密度下的成形状态。

限制与代价

“之字”不等于整层一定是一条连续挤出线，也不意味着它必然比直线更快。Z 向参考等级偏低。

适合用途 一般原型、轻载模型，以及不需要复杂三维内部结构的零件。

实践提醒

不要仅凭路径看起来连续就判断速度；把它与 Z直线放在同一模型中比较切片时间。

04交叉之字Cross Zag可调错位
XY 强度 ★★★☆☆ 中Z 强度 ★☆☆☆☆ 低评分口径 ↗

结构原理 在之字形基础上，根据填充偏移步距使相邻层发生位移，改变各层之间的连接分布。[1]

优势与价值

比固定的层间布局多一个调节手段，可用于比较横向支撑与材料分布。

限制与代价

官方定性等级中，XY 与 Z 的表现并不一致；不能把“交叉”理解为整体强度全面提高。

适合用途 对线型填充做层间布局优化的样件、一般轻载结构。

实践提醒

直接对比总表的两列：交叉之字的 XY 为中（3 星），普通之字为中低（2 星）；两者 Z 都为低（1 星）。按实际受力方向选择。

05限定之字Locked Zag进阶调节
XY 强度 ★★☆☆☆ 中低Z 强度 ★★☆☆☆ 中低评分口径 ↗

结构原理 在之字形骨架外增加一层可单独设置的填充区域。骨架与外侧区域的密度、厚度及互锁深度可以分别调节。[1]

优势与价值

材料可以集中在靠外侧的区域，而不是只用一个全局密度；适合比较骨架与外侧连接的效果。

限制与代价

多组参数会相互影响，官方参考中耗材与耗时都偏高。互锁结构并不等于材料层间熔合已经得到保证。

适合用途 有明确内部骨架设计目标的试验件，不是普通壳体的必要选项。

实践提醒

只改变一个参数后再切片；记录骨架密度与外侧密度，避免把它与普通“20%填充”直接等同。

06线Line速度取向
XY 强度 ★☆☆☆☆ 低Z 强度 ★☆☆☆☆ 低评分口径 ↗

结构原理 一种直线类路径变体。名称与 Z直线相近，但路径调整方式不同，不能仅凭中文名称判断两者完全相同。[1]

优势与价值

参考切片耗时较低，适合先验证外形、装配空间和打印流程。

限制与代价

承载参考等级低；官方比较中材料用量并不比常规图案更少，所以“简单＝最省料”并不成立。

适合用途 快速原型、尺寸试装件和不依赖内部承载的模型。

实践提醒

如果只想省耗材，应比较实际克数，而不是把“线”直接当成闪电或自适应立方体的替代品。

B

网格与立方体系列

从平面网格到三维单元，再到按表面需求分配材料。

07—13
07网格Grid常见图案
XY 强度 ★★★★★ 高Z 强度 ★★★★★ 高评分口径 ↗

结构原理 在同一层内铺设两个交叉方向的线条，形成方格；这与直线填充的逐层换向不同。[1]

优势与价值

结构规则，切片参考耗时较低；在官方定性比较中 XY、Z 等级均较高。

限制与代价

同层交点可能局部堆料并被喷嘴再次经过。顶面支撑不一定优于同耗材的直线填充。

适合用途 已经验证不会明显刮擦的壳体、底座和普通功能件。

实践提醒

PETG 若出现规律性“嗒嗒”擦碰，可先换成不发生同层自交的图案做对照，同时检查流量和速度。

08三角形Triangles平面刚性
XY 强度 ★★★★★ 高Z 强度 ★★★☆☆ 中评分口径 ↗

结构原理 多组方向的直线在单层中组成三角网格，重点是平面内的几何约束。[1]

优势与价值

XY 方向定性等级高，可作为比较平板面内刚性和变形的候选方案。

限制与代价

三线交汇位置有重复挤出风险；平面内刚性不能直接代表板件沿厚度方向的抗弯或层间抗拉性能。

适合用途 以面内载荷为主的板状结构、需要比较平面网格布局的样件。

实践提醒

平板承受垂直于板面的载荷时，先检查板厚及顶底壳厚度，不要只把方格换成三角格。

09内六边形Tri-hexagon多向平面
XY 强度 ★★★★★ 高Z 强度 ★★★★☆ 中高评分口径 ↗

结构原理 三组线条错位形成三角形与六边形的组合。它不是后面那种由连续六边形轮廓构成的蜂窝。[1]

优势与价值

平面内有多个支撑方向；相比三角填充，可避免部分三线汇聚于同一点的情况。

限制与代价

仍有同层交叉，不应当成完全无擦碰的图案；复杂受力仍需要结合外壳设计。

适合用途 需要多方向平面支撑的底板、外壳内部和一般功能件。

实践提醒

与三角形做对照时观察交点突起和实际克数，不要只按视觉上“格子更多”来判断强弱。

10立方体Cubic通用优先
XY 强度 ★★★★★ 高Z 强度 ★★★★★ 高评分口径 ↗

结构原理 线条位置随层高变化，叠成角朝下的立方体单元，形成遍布内部的三维网格。[1]

优势与价值

在官方定性比较中两个方向都处于较高档，参考耗时较低，适合作为功能件的对照基准。

限制与代价

11自适应立方体Adaptive Cubic大件省料
XY 强度 ★★★★☆ 中高Z 强度 ★★★★☆ 中高评分口径 ↗

结构原理 基于立方体，按到边界的距离改变单元尺度：靠近表面较密，体积中心的单元更大。[1]

优势与价值

限制与代价

内部密度并不均匀；小零件可能节省不明显，也不能与固定密度立方体按相同百分比等强比较。

适合用途 大体积外壳、厚实装饰结构，以及不依赖均匀核心承载的模型。

实践提醒

薄壁盒子本身可能几乎没有稀疏填充空间；这时改图案并不会大幅省料，壁厚才是主要变量。

结构原理 在立方体结构基础上增加内部划分，改变空间单元之间的支撑关系。[1]

优势与价值

官方定性参考中 XY、Z 都处于高档，参考耗时与普通立方体接近，可作为另一种三维网格候选。

限制与代价

名称中的“四分之一”不是说只使用四分之一材料，也没有通用的强度倍数优势。

适合用途 希望比较不同三维网格布局的功能件和结构样件。

实践提醒

与立方体保持相同壁厚、材料和实际质量后再测试，不能只比较填充百分比。

13支撑立方体Support Cubic顶面优先

结构原理 主要根据到上方需要承托表面的距离调整填充，重点是支撑顶层，而不是在内部均匀建立承载核心。[1]

优势与价值

实践提醒

有卡扣或螺钉的壳体不宜直接整件套用；可只对非受力区域采用这种填充。

15蜂窝Honeycomb效率需权衡
XY 强度 ★★★★★ 高Z 强度 ★★★★★ 高评分口径 ↗

163D 蜂窝3D Honeycomb空间蜂窝
XY 强度 ★★★★☆ 中高Z 强度 ★★★★☆ 中高评分口径 ↗

结构原理 通过随高度变化的方形和八边形路径形成空间蜂窝，使新一层与前一层保留接触。[1]

优势与价值

17侧向蜂窝Lateral Honeycomb轻量结构

结构原理 把蜂窝结构布置在竖向平面，面向低密度轻量结构；悬垂角参数用于调整层间接触条件。[1]

优势与价值

对机翼等轻量结构有针对性，可在较低填充量下研究抗扭与外形保持。

限制与代价

综合定性等级不高，方向与模型姿态很重要；不是通用高负载填充。

适合用途 模型机翼、轻量长条构件和专门设计的薄壳结构。

先确认载荷方向和摆放方向。改变打印姿态后，原来有效的侧向布局可能不再合适。

18侧向晶格Lateral Lattice柔性取向
XY 强度 ★★☆☆☆ 中低Z 强度 ★☆☆☆☆ 低评分口径 ↗

结构原理 两组晶格元素各有一个沿 Z 方向的倾角，可通过两个角度参数改变内部支撑方向。[1]

优势与价值

柔性材料的硬度和外壳厚度同样关键；同一图案换一种 TPU，也可能得到很不同的手感。

19交叉层叠Cross Hatch通用备选
XY 强度 ★★★★☆ 中高Z 强度 ★★★★☆ 中高评分口径 ↗

结构原理 用较多直线与折线组织三维连接，可视为与 Gyroid 思路相近但路径更线性的一种方案。[1]

20TPMS-D结构TPMS-D · Schwarz Diamond结构试验
XY 强度 ★★★★★ 高Z 强度 ★★★★★ 高评分口径 ↗

结构原理 基于 Schwarz Diamond 类型的三周期极小曲面（TPMS）生成切片路径，是周期性连续几何的一种。[1]

优势与价值

把“层数”换成实际厚度

0.20 mm 层高下，5 层顶面约为 1.0 mm。层高改成 0.12 mm，仍用 5 层只剩约 0.6 mm；同样的层数不代表相同的壳厚。启用可变层高时尤其要检查最小壳厚设置。[4]

壁数也不是精确壁厚

实际厚度会受到线宽、相邻线重叠及墙生成器影响。4 道壁只是一个便于试切的设定，最终应查看切片后的真实路径与局部厚度。[4]

复制两套基础试切参数

复制的是文字清单，不是可直接导入切片器的预设文件。

关键载荷

持续载荷、热环境、冲击或安全相关用途，需要明确的设计与验证。不要把任何密度范围、图案名称或五星评级当作安全系数。

05

常见误区与打印排障

把几何问题、材料问题和工艺问题分开，避免只在填充下拉框里反复尝试。

误区 1星级相同，承重就相同

不是。XY 与 Z 星级各自只是方向性定性参考，不包含模型尺寸、载荷类型、破坏模式与安全系数。某一列同为五星，也不代表实物承载能力相同。

误区 2网格必然最能托住顶面

不是。相同材料用量下，直线填充可能有更密的支撑线；还要看第一层实心顶面的桥接方向与有效跨距。

误区 3TPMS 或 Gyroid 能消除层间弱点

不能。理想几何的方向均衡，不等于逐层挤出的成品各向同性；打印方向与层间熔合仍然重要。

误区 4提高填充比加壁永远更有效

没有这种通则。壳体、悬臂、局部压缩和螺钉夹紧的材料需求不同；按失效位置决定先加哪里。

误区 5所有图案的 20% 都等于同样克数

不是。密度计算、路径调整和自适应分布会改变实际耗材；闪电尤其不能当作均匀体积填充理解。

误区 6换成 Gyroid 就能修好 PETG

不保证。图案只能改变路径；受潮、过量挤出、温度、速度与体积流量问题仍需单独排查。

遇到问题，先检查这些位置

现象优先检查更有效的下一步
喷嘴规律性刮擦交点突起、挤出过量、局部翘起。同参数试切 Z直线或 Gyroid；校验流量、材料预设与速度，观察刮擦是否仍发生。
顶面下陷／枕状鼓包支撑间距、顶面桥接方向、壳厚与冷却。先看第一层顶面实心路径；局部加密或增加实际顶壳厚度，不必整件大幅加填充。
螺丝孔或卡扣附近破裂孔边壁数、夹紧路径、根部圆角和打印方向。用局部修改器加强关键区域，优化几何；不要依赖远离受力点的中心填充。
沿层缝撕开载荷是否沿层间剥离，温度／速度／冷却是否合适。优先调整朝向、几何与工艺；换一个“五星图案”不等于解决层间失效。
曲面填充比预期更慢短线段、加速度限制、机器实际运动表现。区分切片耗时与打印耗时；用同一模型比较立方体、交叉层叠与 Gyroid。

评分口径、范围与资料来源

01 / XY 与 Z 分开评级

将参考资料中的“低、中低、中、中高、高”分别映射为 1–5 星，XY 与 Z 各自保留原等级，不再取两者较低值，也不做平均。总表和 26 项详解使用同一套分项星级。

例如三角形显示 XY 5 星、Z 3 星；直线排列显示 XY 2 星、Z 3 星。XY 是平行打印平台的平面内方向，Z 是沿打印高度的方向；这些星级并非拉伸、压缩、抗弯或层间粘接的实测数值。[2]

低 → ★☆☆☆☆　中低 → ★★☆☆☆
中 → ★★★☆☆　中高 → ★★★★☆
高 → ★★★★★

02 / 速度与省料是逆向映射

它们衡量的是参考切片耗时与材料用量，不是实际 mm/s，也不是特定零件的“每克强度”。为保留五档显示，把相邻的高耗时／高用料等级适度合并。

速度：耗时极低／低 → 5；中低 → 4；中 → 3；中高／高 → 2；很高／极高 → 1。
省料：用料极低／很低 → 5；低／中低 → 4；常规 → 3；中高／高 → 2；很高／极高 → 1。

03 / 参考比较并不是拉伸试验

官方说明：强度等级由人工设置；材料与时间参考来自 100 mm 方块、3DBenchy 和 Stanford bunny，在 5%、15%、30%、50% 填充、去除墙及顶底壳的条件下切片比较。[2]

因此不能直接推算你的带外壳模型的承载值、完整打印时间或节省比例。真实运动限制也可能改变速度顺序。

04 / 范围按截图固定为 26 项

中文名保留截图习惯；“侧向向晶格”这类重复译名在正文统一为“侧向晶格”。对应英文 Lateral Lattice。螺旋体对应 Gyroid，而不是花瓶模式。

不同软件、分支和版本的图案及参数不一定完全一致。本文不把所有项目都宣称为 Bambu Studio 或任何特定 Anycubic 版本的现成功能。
